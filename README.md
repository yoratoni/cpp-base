Notes
-----
- This boilerplate is specifically for C++ projects on Windows (with `MSYS2`),
  check how to set up the environment [here](https://www.msys2.org/).
    - For VSCode users, check [here](https://code.visualstudio.com/docs/cpp/config-mingw) for
      how to set up the C++ environment.
    - Don't forget to install CMake from the `MSYS2` package manager (`pacman -S mingw-w64-ucrt-x86_64-cmake`).
